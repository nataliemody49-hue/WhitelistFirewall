# جدار الحماية (Whitelist Firewall)

يقطع الإنترنت عن كل التطبيقات إلا التي تختارها، ومحمي بكلمة سر.

## الحصول على ملف APK
1. أنشئ مستودعاً جديداً على github.com (Private أو Public).
2. ارفع كل محتويات هذا المجلد إليه (بما فيها مجلد .github).
3. افتح تبويب Actions، وانتظر اكتمال "Build APK" (3-6 دقائق).
4. افتح التشغيل المكتمل ونزّل الملف من قسم Artifacts باسم firewall-apk، ثم فك الضغط لتجد app-debug.apk.
